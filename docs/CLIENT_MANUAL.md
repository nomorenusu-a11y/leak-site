# 사이트 운영 매뉴얼

이 문서는 사이트 관리자(사장님)가 직접 보는 안내서입니다.
컴퓨터·스마트폰 모두 같은 방식으로 동작합니다.

---

## 1. 첫 로그인

1. 브라우저 주소창에 사이트 도메인 + `/admin/login` 입력
   예: `https://본도메인/admin/login`
2. 비밀번호 입력 후 **로그인** 버튼
3. 로그인되면 좌측에 메뉴가 보이는 관리자 페이지로 이동

> 비밀번호를 잊었거나 바꾸고 싶으면 개발자(저)에게 연락주세요.

> ![로그인 페이지 자리](./screenshots/login.png)

---

## 2. 새 견적이 들어왔어요. 어떻게 처리하나요?

### 빠른 흐름

1. 좌측 메뉴 **"견적 신청"** 클릭
2. 새로 들어온 항목(가장 위) 클릭
3. 상세 페이지에서 다음 순서로 처리:
   - **빠른 액션** 영역의 📞전화 또는 💬카톡 버튼으로 손님에게 바로 연락
   - 상담 후 **상태 변경** 드롭다운에서 적절한 상태 선택:
     - `접수` — 들어왔는데 아직 연락 못함
     - `견적발송중` — 상담 후 견적 안내 단계
     - `작업중` — 시공 진행 중
     - `작업완료` — 끝난 건
   - 필요하면 **관리자 메모**에 현장 메모, 약속 시간 등 자유롭게 입력 (자동 저장됨)
4. **공개 보드 노출** 토글:
   - ON(초록색) — 홈페이지 "실시간 작업 현황"에 마스킹된 이름으로 노출 (예: `홍o동`)
   - OFF(회색) — 보드에서 즉시 숨김

> ![견적 상세 자리](./screenshots/request-detail.png)

### 손님 정보 공개에 대해

손님의 실제 이름·연락처는 **공개 보드에 절대 노출되지 않습니다**. 보드에는 마스킹된 이름만 표시됩니다 (예: `홍o동`, `김o`, `Rot`).

### 견적을 삭제하고 싶을 때

견적 상세 페이지 오른쪽 상단 **"이 신청 삭제"** 버튼. 한 번 더 확인하는 창이 뜨고, 확인을 누르면 영구 삭제됩니다 (되돌릴 수 없음).

## 3. 시공 사례 글을 어떻게 작성하나요?

### 빠른 흐름

1. 좌측 메뉴 **"시공 사례"** → 우측 상단 **"+ 새 글 작성"**
2. 필드 채우기:
   - **제목** — 검색에 잘 걸리는 형태로. 예: "강남구 역삼동 안방 천장 누수 — 비파괴 정밀 탐지로 해결"
   - **슬러그** — 영문 URL 부분. 자동으로 채워지지만 수정 가능. 영문 소문자·숫자·하이픈만.
   - **카테고리** — 누수 탐지 / 누수 시공 / 방수 / 배관 / 기타 중 선택
   - **발행 상태** — 체크하면 즉시 사이트에 노출, 해제하면 임시저장
3. **지역 태그** — 글이 노출될 지역 칩 클릭 (여러 개 선택 가능)
   - 예: 강남구 글이면 "강남구" 선택
   - 이 태그가 `/posts/region/강남` 같은 지역별 페이지에 글을 노출시킵니다
4. **대표 이미지** — 글 카드에 표시되는 표지 사진. 파일 선택 → 자동 업로드 → 미리보기
5. **요약 (선택)** — 비워두면 본문 첫 150자가 자동 사용됨. 검색 결과·SNS 공유 미리보기에 사용
6. **본문 (Markdown)** — 좌측에서 작성, 우측에 실시간 미리보기
   - `## 소제목`, `- 목록 항목`, `**굵게**` 등 Markdown 문법
7. **글 생성** 버튼

> ![글 작성 자리](./screenshots/post-new.png)

### 현장 사진은 어떻게 첨부하나요?

**글을 처음 만들 때는 추가 이미지 첨부 영역이 없습니다.** 글을 한 번 저장한 뒤 편집 화면(`/admin/posts/...편집`)에서 추가 이미지를 올릴 수 있습니다. 여러 장 한 번에 선택 가능.

### Markdown 간단 치트시트

| 쓰고 싶은 형태 | Markdown |
|---|---|
| 큰 제목 | `## 제목` |
| 굵게 | `**굵게**` |
| 글머리 기호 | `- 항목` |
| 번호 매기기 | `1. 항목` |
| 인용 | `> 인용문` |
| 코드 한 줄 | `` `text` `` |

## 4. "강남 누수"로 검색했을 때 우리 글이 잘 뜨려면?

핵심: **글의 지역 태그를 정확히 선택하세요.**

1. 글 작성·편집 페이지에서 **지역 태그** 영역의 **"강남구"** 칩 클릭 (선택됨 = 파란색)
2. 글이 자동으로 `/posts/region/gangnam` 페이지에 함께 노출됨
3. 페이지 제목과 메타 설명에 "강남구"가 들어가 검색엔진이 해당 지역 글로 인식

### 더 잘 노출되게 하는 팁

- **제목에 지역명 포함**: "강남구 누수 시공 — ..."
- **본문 첫 단락에 지역명 + 증상 자연스럽게 1~2회 언급**
- **요약 필드를 직접 입력**해 검색 결과 미리보기 문구를 컨트롤
- 한 글에 여러 지역 태그를 동시에 다는 건 OK (예: "강남구" + "서초구"). 단, **실제 시공이 그 지역이 아니면 달지 마세요** — 검색 신뢰도가 떨어집니다.

---

## 5. 글을 수정·삭제하고 싶을 때

- **수정**: "시공 사례" 목록 → 글 제목 또는 "편집" 클릭 → 변경 후 **변경사항 저장**
- **임시 비공개**: 편집 화면에서 **발행 상태** 체크 해제 후 저장 → 사이트에서 즉시 숨김 (글 자체는 유지)
- **영구 삭제**: 목록의 "삭제" 버튼. 확인창에서 한 번 더 확인 → 글 + 첨부 이미지 모두 영구 삭제

## 6. 자주 묻는 질문

### Q. 비밀번호를 자주 바꿔야 하나요?
A. 의심스러운 일이 있을 때만 바꿔도 충분합니다. 변경은 개발자(저)에게 연락 주세요.

### Q. 휴대폰으로도 작업할 수 있나요?
A. 모든 페이지가 모바일에서도 동작합니다. 좌측 상단 **"메뉴"** 버튼으로 사이드바를 열 수 있습니다.

### Q. 사진을 잘못 올렸어요. 다시 올릴 수 있나요?
A. 편집 화면의 사진 위 **"삭제"** 버튼을 누르면 즉시 사라집니다. 다시 파일을 선택해서 업로드하세요.

### Q. 글을 작성했는데 사이트에 안 보여요.
A. 편집 화면에서 **발행 상태** 체크 박스가 켜져 있는지 확인하세요. 체크 안 되어 있으면 임시저장 상태입니다.

### Q. 새 견적이 들어왔는데 알림이 안 와요.
A. 현재 버전은 이메일·문자 알림 없이 페이지에서 직접 확인하는 방식입니다. 알림 기능이 필요하면 개발자에게 요청 주세요.

### Q. 누수 신청이 너무 많아 공개 보드에 일부만 보이게 하고 싶어요.
A. 견적 상세 → **공개 보드 노출** 토글 OFF로 해당 신청만 숨길 수 있습니다.

---

## 7. 도움이 필요할 때

- **사이트가 안 열려요** → 잠시 후 다시 시도. 계속 안 되면 개발자에게 연락
- **로그인이 안 돼요** → 5분 후 다시 시도 (보안상 잘못 시도 5회 시 잠시 차단)
- **다른 질문** → 개발자에게 연락

> 이 문서의 스크린샷은 실제 배포 후 추가될 예정입니다.
