1

도메인이란?

도메인(Domain)은 인터넷에서 웹사이트를 찾을 때 사용하는 고유한 주소입니다. 마치 우리가 집을 찾을 때 주소를 사용하는 것처럼, 인터넷에서도 웹사이트마다 고유한 주소가 있습니다.

도메인은 복잡한 숫자 주소 대신 사람이 기억하기 쉬운 이름입니다

숫자 주소 (IP)
76.76.21.21
➔
도메인 주소
nususigong.com

어려운 숫자 대신 기억하기 쉬운 이름으로 접속할 수 있습니다

일상에서 보는 도메인 예시:

  • naver.com — 네이버
  • google.com — 구글
  • coupang.com — 쿠팡

왜 도메인이 필요한가요?

이유 설명
🎯 전문성 leak-site.vercel.app보다 nususigong.com이 훨씬 전문적이고 신뢰감을 줍니다.
💭 기억하기 쉬움 고객이 기억하기 쉬운 짧고 간단한 주소를 사용할 수 있습니다. 명함이나 광고에 넣기도 좋습니다.
📈 마케팅 효과 자체 도메인은 브랜드 이미지를 높이고, 네이버/구글 검색에서도 더 유리합니다 (SEO 효과).
🔒 소유권 vercel.app 주소는 Vercel이 제공하는 것이므로 언제든 변경될 수 있지만, 내 도메인은 내가 소유합니다.
💡
팁 현재 사이트 주소 leak-site.vercel.app은 계속 사용 가능합니다. 새 도메인을 연결하면 두 주소 모두 같은 사이트로 접속됩니다.
2

가비아 회원가입

가비아(Gabia)는 국내에서 가장 많이 사용되는 도메인 등록 업체입니다. 도메인을 구매하려면 먼저 가비아에 회원가입을 해야 합니다.

  1. 웹 브라우저에서 gabia.com에 접속합니다.
    • 크롬, 엣지, 사파리 등 아무 브라우저나 사용 가능합니다.
  2. 화면 오른쪽 상단의 회원가입 버튼을 클릭합니다.
  3. 이용약관에 동의합니다.
    • 전체 동의를 체크하면 편리합니다.
  4. 회원 정보를 입력합니다.
    • 아이디: 영문+숫자 조합으로 설정
    • 비밀번호: 영문+숫자+특수문자 조합 (8자 이상)
    • 이메일: 실제 사용하는 이메일 주소 입력 (도메인 관련 알림 수신용)
    • 연락처: 휴대폰 번호 입력
  5. 본인인증을 진행합니다.
    • 휴대폰 본인인증 또는 아이핀 인증 중 선택
    • 휴대폰 인증이 가장 간편합니다
  6. 가입 완료! 입력한 아이디와 비밀번호로 로그인합니다.
⚠️
주의 회원가입 시 입력하는 이메일 주소는 반드시 실제 사용하는 것으로 입력하세요. 도메인 만료 안내, 인증 메일 등 중요한 알림이 이 이메일로 발송됩니다.
3

도메인 검색 및 구매

이제 원하는 도메인을 검색하고 구매할 차례입니다. 도메인은 전 세계에서 하나만 존재하기 때문에, 이미 다른 사람이 사용 중인 도메인은 구매할 수 없습니다.

3-1. 도메인 검색

  1. 가비아 홈페이지 메인 화면의 도메인 검색창에 원하는 도메인 이름을 입력합니다.
    • 예시: nususigong, 유레카누수, eureka-nusoo 등
    • 뒤의 .com, .kr 등은 입력하지 않아도 됩니다.
  2. 검색 버튼을 클릭하면 사용 가능한 도메인 목록이 표시됩니다.
    • ✅ 등록 가능 — 구매할 수 있는 도메인
    • ❌ 등록 불가 — 이미 다른 사람이 사용 중인 도메인

3-2. 도메인 종류 비교

도메인 뒤에 붙는 확장자(.com, .kr 등)를 최상위 도메인(TLD)이라고 합니다. 주요 차이점은 다음과 같습니다.

.com
전 세계 공용
가장 보편적
연 약 11,000 ~ 16,000원
⭐ 추천
.kr
대한민국 국가 도메인
짧고 깔끔
연 약 17,000 ~ 22,000원
.co.kr
대한민국 기업용
전통적으로 많이 사용
연 약 17,000 ~ 22,000원
💡
추천 처음이라면 .com을 추천합니다. 전 세계 어디서나 통용되고, 가격도 가장 저렴하며, 대부분의 사람들이 가장 익숙하게 느끼는 확장자입니다.

3-3. 도메인 구매 (결제)

  1. 원하는 도메인 옆의 선택 버튼을 클릭합니다.
  2. 등록 기간을 선택합니다.
    • 최소 1년부터 선택 가능합니다.
    • 1년 단위로 갱신할 수 있으므로 처음에는 1년을 추천합니다.
  3. 장바구니에 담긴 도메인을 확인하고 결제하기를 클릭합니다.
  4. 결제 수단을 선택합니다.
    • 신용카드 / 체크카드
    • 무통장입금 (가상계좌)
    • 간편결제 (카카오페이, 네이버페이 등)
  5. 결제가 완료되면 도메인이 즉시 등록됩니다. 등록 완료 알림이 이메일로 발송됩니다.
⚠️
자동갱신 설정을 꼭 해주세요! 도메인은 1년마다 갱신해야 합니다. 갱신하지 않으면 도메인이 만료되어 사이트에 접속할 수 없게 됩니다. My가비아 > 도메인 관리에서 자동갱신을 켜두면 만료 전 자동으로 결제되어 안전합니다.
4

Vercel에 도메인 연결

도메인을 구매했으면, 이제 Vercel에 "이 도메인을 사용하겠다"고 알려줘야 합니다. 아래 순서대로 진행하세요.

Vercel 로그인 ➔ 프로젝트 선택 ➔ Settings ➔ Domains ➔ 도메인 입력
  1. vercel.com에 접속하여 로그인합니다.
    • GitHub 계정으로 로그인하면 됩니다.
  2. 대시보드에서 leak-site 프로젝트를 클릭합니다.
  3. 상단 메뉴에서 Settings 탭을 클릭합니다.
  4. 왼쪽 사이드바에서 Domains를 클릭합니다.
  5. 입력창에 구매한 도메인을 입력합니다.
    • 예: nususigong.com
    그리고 Add 버튼을 클릭합니다.
  6. Vercel이 DNS 설정 안내를 보여줍니다.
    • 이 화면에 나오는 정보(A 레코드, CNAME 등)를 메모하거나 화면을 열어둡니다.
    • 다음 섹션(가비아 DNS 설정)에서 이 정보를 사용합니다.
💡
www 서브도메인 Vercel에서 도메인을 추가하면 www.nususigong.com도 함께 추가할지 묻습니다. "Add www.nususigong.com and redirect to nususigong.com"을 선택하면 www 유무 상관없이 모두 접속 가능하게 됩니다. 이 옵션을 선택하세요.
⚠️
아직 사이트가 연결되지 않습니다 이 단계까지만 하면 Vercel 측 설정은 완료되지만, 아직 가비아에서 DNS 설정을 하지 않았으므로 도메인으로 접속하면 오류가 뜹니다. 반드시 다음 섹션(5. 가비아 DNS 설정)을 이어서 진행하세요.
5

가비아 DNS 설정

이 단계는 가비아에서 "이 도메인은 Vercel 서버로 연결해라"라고 설정하는 과정입니다. DNS(Domain Name System)는 도메인 이름을 실제 서버 주소로 변환해주는 시스템입니다.

DNS 설정의 원리

사용자가
nususigong.com
입력
➔
가비아 DNS
어디로 보낼까?
➔
Vercel 서버
76.76.21.21
  1. gabia.com에 로그인합니다.
  2. 오른쪽 상단의 My가비아를 클릭합니다.
  3. 도메인 섹션에서 관리 버튼을 클릭합니다.
  4. 구매한 도메인(예: nususigong.com) 옆의 관리 버튼을 클릭합니다.
  5. DNS 관리 또는 DNS 설정 버튼을 찾아 클릭합니다.
    • "DNS 레코드 설정" 또는 "DNS 관리 툴"이라고 표시될 수도 있습니다.
  6. 아래의 DNS 레코드 2개를 추가합니다.

추가할 DNS 레코드

레코드 타입 호스트/이름 값/콘텐츠 TTL
A @ 76.76.21.21 3600 (기본값)
CNAME www cname.vercel-dns.com 3600 (기본값)
💡
각 항목의 의미
  • A 레코드: 도메인(nususigong.com)을 Vercel 서버 IP 주소(76.76.21.21)로 연결합니다.
  • CNAME 레코드: www.nususigong.com을 Vercel DNS 서버로 연결합니다.
  • @: "도메인 자체"를 의미합니다 (www 없이 접속할 때).
  • TTL: DNS 캐시 유지 시간입니다. 기본값(3600초 = 1시간)을 사용하세요.

DNS 레코드 추가 방법 (가비아 화면)

  1. DNS 관리 화면에서 레코드 추가 또는 + 추가 버튼을 클릭합니다.
  2. 첫 번째 레코드 (A 레코드) 입력:
    • 타입: A 선택
    • 호스트: @ 입력
    • 값/IP주소: 76.76.21.21 입력
    • TTL: 기본값 유지
  3. 두 번째 레코드 (CNAME 레코드) 입력:
    • 타입: CNAME 선택
    • 호스트: www 입력
    • 값/도메인: cname.vercel-dns.com 입력
    • TTL: 기본값 유지
  4. 저장 또는 확인 버튼을 클릭합니다.
✅
저장 완료! DNS 설정이 저장되었습니다. 이제 인터넷 전체에 이 정보가 퍼지는 데 시간이 걸립니다. 보통 10분 ~ 1시간 정도면 적용되지만, 최대 48시간까지 소요될 수 있습니다.
⚠️
기존 DNS 레코드 확인 만약 이미 A 레코드나 CNAME 레코드가 있다면, 기존 값을 위의 값으로 수정하세요. 같은 타입의 레코드가 중복되면 문제가 발생할 수 있습니다.
6

SSL 인증서 (HTTPS)

SSL 인증서는 사이트와 방문자 사이의 통신을 암호화하여 보안을 강화하는 기술입니다. SSL이 적용된 사이트는 주소가 https://로 시작하며, 브라우저 주소창에 자물쇠 아이콘이 표시됩니다.

🎉
좋은 소식: 별도 설정이 필요 없습니다! Vercel은 도메인을 연결하면 자동으로 무료 SSL 인증서를 발급해줍니다. 별도의 구매나 설정 없이, DNS 연결이 완료되면 자동으로 HTTPS가 활성화됩니다.

SSL 적용 확인 방법:

  1. 브라우저에서 https://nususigong.com (본인의 도메인)으로 접속합니다.
  2. 주소창 왼쪽에 자물쇠 아이콘 🔒이 표시되는지 확인합니다.
  3. 자물쇠 아이콘을 클릭하면 "연결이 안전합니다" 또는 "Connection is secure" 메시지가 나타납니다.
💡
팁 SSL 인증서 발급에는 DNS 설정 완료 후 몇 분 ~ 최대 1시간 정도 소요될 수 있습니다. 만약 "이 사이트는 안전하지 않습니다" 경고가 뜨면, 조금 기다린 후 다시 시도하세요.
7

확인 및 테스트

모든 설정이 완료되었습니다! 이제 도메인이 제대로 작동하는지 확인해봅시다. 아래 체크리스트를 하나씩 확인하세요.

  • 도메인 접속 확인
    브라우저에서 nususigong.com (본인의 도메인)을 입력하여 사이트가 정상적으로 표시되는지 확인합니다.
  • www 접속 확인
    www.nususigong.com으로도 접속해봅니다. 같은 사이트가 표시되어야 합니다.
  • HTTPS 확인
    주소창에 자물쇠 아이콘이 표시되고, https://로 시작하는지 확인합니다.
  • 모바일 접속 확인
    스마트폰에서도 도메인을 입력하여 사이트가 잘 보이는지 확인합니다.
  • 기존 주소 확인
    leak-site.vercel.app으로도 여전히 접속 가능한지 확인합니다.
💡
Vercel 대시보드에서 상태 확인 Vercel 대시보드 > 프로젝트 > Settings > Domains에서 도메인 상태를 확인할 수 있습니다.
  • ● Valid Configuration — 정상 연결 완료
  • ● Pending Verification — DNS 설정 대기 중 (시간이 좀 더 필요합니다)
  • ● Invalid Configuration — DNS 설정 오류 (설정값을 다시 확인하세요)
⚠️
접속이 안 되나요? DNS 변경 후 최대 48시간까지 소요될 수 있습니다. 1시간 정도 기다린 후 다시 시도해보세요. 그래도 안 되면 섹션 5의 DNS 레코드 값이 정확한지 다시 확인하세요.
8

환경변수 업데이트

사이트 내부에서 사용하는 주소(URL)도 새 도메인으로 바꿔줘야 합니다. 이 설정을 하지 않으면 사이트 내 일부 기능(공유 링크, SEO 등)이 여전히 이전 주소(leak-site.vercel.app)를 사용할 수 있습니다.

Vercel 대시보드 ➔ Settings ➔ Environment Variables ➔ 값 수정 ➔ 재배포
  1. Vercel 대시보드에서 leak-site 프로젝트를 선택합니다.
  2. 상단 메뉴에서 Settings 탭을 클릭합니다.
  3. 왼쪽 사이드바에서 Environment Variables를 클릭합니다.
  4. 환경변수 목록에서 NEXT_PUBLIC_SITE_URL을 찾습니다.
    • 없으면 새로 추가합니다.
  5. 값을 새 도메인으로 변경합니다.
# 변경 전 (기존 값)
NEXT_PUBLIC_SITE_URL=https://leak-site.vercel.app

# 변경 후 (새 도메인)
NEXT_PUBLIC_SITE_URL=https://nususigong.com
  1. Save 버튼을 클릭하여 저장합니다.
  2. 재배포를 합니다.
    • 상단 메뉴에서 Deployments 탭을 클릭합니다.
    • 가장 최신 배포(맨 위) 오른쪽의 점 세 개 (⋮) 메뉴를 클릭합니다.
    • Redeploy를 선택합니다.
    • 확인 팝업에서 Redeploy 버튼을 클릭합니다.
✅
완료! 재배포가 완료되면 (보통 1~2분 소요) 사이트가 새 도메인 주소를 올바르게 사용하게 됩니다.

📅 도메인 만료 관리

도메인은 영구 소유가 아닌 임대 개념입니다. 매년 갱신 비용을 지불해야 하며, 갱신하지 않으면 도메인이 만료되어 다른 사람이 구매할 수 있게 됩니다.

⚠️
매우 중요: 자동갱신을 반드시 설정하세요! 도메인이 만료되면 사이트에 접속할 수 없게 되고, 다른 사람이 그 도메인을 구매해버리면 되찾기 매우 어렵습니다. My가비아 > 도메인 관리 > 자동갱신 설정을 꼭 켜두세요.

🔧 자주 발생하는 문제와 해결 방법

문제 해결 방법
도메인으로 접속하면 "사이트에 연결할 수 없음" DNS 설정이 아직 반영되지 않았을 수 있습니다. 1시간 후 다시 시도하세요. 그래도 안 되면 가비아 DNS 레코드 값이 정확한지 확인하세요.
Vercel에서 "Invalid Configuration" 표시 가비아 DNS 레코드의 값이 잘못되었을 가능성이 높습니다. A 레코드가 76.76.21.21로, CNAME이 cname.vercel-dns.com으로 정확히 설정되어 있는지 확인하세요.
"이 연결은 안전하지 않습니다" 경고 SSL 인증서가 아직 발급되지 않았습니다. DNS 설정 후 최대 1시간 기다려주세요. Vercel이 자동으로 발급합니다.
www는 되는데 www 없이는 안 됨 (또는 반대) A 레코드(@)와 CNAME 레코드(www) 둘 다 올바르게 설정되어 있는지 확인하세요.
이전 vercel.app 주소로 접속 안 됨 이런 경우는 거의 없지만, Vercel 대시보드에서 leak-site.vercel.app이 도메인 목록에 여전히 있는지 확인하세요. 삭제하지 마세요.
